# Main Repository: Analyse_Images_des_cellules

Welcome to the main repository for Rapport_Selahiye_Aras! This repository contains various resources related to the ProjetAnalyseImage for counting cells.

## Getting Started

To get started with the project:

1. **Rapport:** Navigate to the "Rapport" directory for the main project report.

2. **Figures:** Explore the "Figures" sub-repository for visual representations and illustrations related to the project.

3. **Imj Macro:** The "Imj Macro" sub-repository contains a single ImageJ macro. If you want to experiment with the ImageJ macro or run it on your own datasets, navigate to this directory.
   - In order to run the macro, go to the CellCount5.imj, change the directoryPath variable to the path where you have your "noyaux.tif" original image stack. Then open ImageJ and go to Plugins -> Macros -> New -> Open, and choose CellCount5.imj.
   - Additionally, changing "noyaux.tif" to another image will enable you to count the number of particles of any desired image containing cells of enough diameter.

4. **Output Data:** Explore the "Output Data" sub-repository for example output files generated by the ImageJ macro. Understand the format and structure of the output data.

5. **Output Data from Failed Attempts:** In the "Output Data from Failed Attempts" sub-repository, you'll find output files and Python scripts from failed attempts. Understanding these files may provide insights into potential issues or challenges faced during the project.

Feel free to reach out if you have any questions or need assistance!
